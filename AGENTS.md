# Repository instructions

Build practical, truthful tools that improve the accessibility and consistency of merchant product information.
Use Python 3.9+ standard library for the CLI. Run `python3 -m unittest discover -s tests -v` before publishing.
Keep public examples fictional and marked as demo; never invent identifiers, reviews, certifications, rankings, or product claims for a real merchant.
No automatic vendor submission, crawling, purchasing, or production-site changes. Validate untrusted input and escape HTML, XML, JSON-LD and URL output.
Distinguish local data validation from public reachability, platform acceptance, indexing, recommendation and commercial results.
Verify vendor formats against current primary documentation; record verification dates and limitations.
Do not publish secrets or private customer data. Explicitly authorized maintainer contact information is allowed.
