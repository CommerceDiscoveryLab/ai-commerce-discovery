# 项目品牌与 GitHub 地址

项目名称是 **AI Commerce Discovery**，仓库名是 `ai-commerce-discovery`。名称、README、描述和主题标签都围绕电商与商品发现，不以个人姓名作为产品品牌。

GitHub 仓库地址必须为 `github.com/账号或组织/仓库名`。个人账号下保留个人命名空间是标准定位方式；它本身不意味着 AI 无法理解项目。搜索是否收录及推广效果应实际验证，不能只根据路径作结论。

若需要品牌地址，可用 GitHub Free 创建独立组织，例如 **CommerceDiscoveryLab**，再采用：

```text
https://github.com/CommerceDiscoveryLab/ai-commerce-discovery
```

这是建议的未来地址，在组织与迁移成功前不能当作已存在的项目链接。组织名可用性须以 GitHub 创建页面为准；查询 API 不存在不代表名称一定可注册。

创建路径：在自己的 GitHub 登录后进入 Settings → Organizations → New organization，选择合适计划，完成组织设置。免费公开工具通常可从 Free 开始；不要为本项目自动购买付费计划。验证码、账户验证和条款确认由账号所有者完成。

组织建好后，由维护者正常迁移或在组织中创建仓库，更新远程地址、README 克隆命令与对外链接。无需改个人 GitHub 用户名，也无需迁移其他项目。

[GitHub 官方组织创建说明](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/creating-a-new-organization-from-scratch)
